---

## How this board works

- **One file appears in exactly one non-terminal task at a time.** Before adding a task, search this file for every path it owns; a collision means re-scoping, not sharing.
- **Statuses:** `NOT STARTED` → `IN PROGRESS` → `PR OPEN` → `MERGED`. Side states: `BLOCKED(reason)`, `CUT(date)`, `SKIPPED(no fixture)`.
- **Status updates happen twice a day:** when the founder assigns/merges (live), and at the 21:00 review (sweep). Agents do not edit this file; they report status in HANDOFF.md and the founder syncs it here.
- **The Depends-on column is the scheduler.** A task does not start while a dependency is not `MERGED`/`DONE`. Founder tasks (no branch) gate agent tasks constantly; that is by design.
- **Branches:** `agent/<tool>/<topic>`, one per task, cut from current main. Founder tasks run on main or no branch.
- **Merge order within any day:** Codex contracts → Claude Code engines → Antigravity components.
- **Blocked protocol:** an agent that hits a STOP-and-ask trigger (AGENTS.md §1) writes the question in HANDOFF.md, sets nothing here, and stops. The founder answers in the spec doc, flips the status back, and the agent resumes with the updated spec.
